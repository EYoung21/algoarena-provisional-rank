## Problem Statement

In AlgoArena, each player has two values: Actual Rank and Public Rank.

A player's Public Rank is equal to their Actual Rank if they have played in 10 or more matches. Otherwise, if they have played K matches, their Public Rank is their Actual Rank minus 100 x (10 - K).

A certain player has played in N matches, and their Public Rank is R. Find their Actual Rank.

## Constraints

```
- All values in input are integers.
- 1 <= N <= 100
- 0 <= R <= 4111
```

## Input

```
Input is given from Standard Input in the following format:

N R
```

## Output

```
Print the player's Actual Rank.
```

## Input

```
2 2919
```

## Output

```
3719
```

## Input

```
22 3051
```
